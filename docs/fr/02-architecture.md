# Silo Finance : architecture

L’architecture sépare les contrats de base, les modules spécialisés et les intégrations. Cette séparation rend les responsabilités lisibles : isolated markets, share tokens, debt, interest model, hooks, flash loans, liquidation. Les paramètres critiques doivent toujours être vérifiés dans la version déployée.
